# Publish an Unfairly Intelligence learning

Summarize the reusable workflow, not the private work product. Include the goal, tools and skills used, ordered steps, verification method, common failures, and resulting artifact type. Exclude prompts, responses, secrets, source code, customer data, file contents, and raw command output. Ask the employee to approve the proposed playbook before publishing it through Unfairly.
